# Security

This project is pre-release and has no supported stable release series yet.
Use the latest reviewed commit and pin it explicitly.

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/fusion44/rune-material/security/advisories/new).
The maintainer must enable that feature before release. Do not post sensitive
data, credentials or exploit details in a public issue. If private reporting is
unavailable, open an issue requesting a private reporting channel without details.

Dependency scans cover known advisories, not a complete security assessment.
Rune and its Git-pinned patches are part of the trusted dependency surface.
