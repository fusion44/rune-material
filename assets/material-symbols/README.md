Paths: `symbols/web/<name>/materialsymbolsrounded/<name>[_fill1]_24px.svg`

These are official Rounded symbols, weight 400, optical size 24, grade 0.
Folders use FILL=1; other symbols use FILL=0. Google's path data is unchanged;
a group transform normalizes the original `0 -960 960 960` viewBox to 24×24
because Rune's icon renderer does not apply SVG viewBox offsets.

Regenerate with `python3 scripts/update-material-icons.py`. The application
embeds the SVGs at compile time; no icon font or network access is needed.
